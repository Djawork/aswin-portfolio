# Aswin — Architecture & 3D Visualization Portfolio

A responsive, single-page portfolio starter built with plain HTML, CSS and JavaScript.

## Included
- Desktop hover-to-expand accordion panels
- Click and keyboard selection
- Mobile tap-to-expand interaction
- Dark cinematic styling and responsive layout
- About and contact sections

## Preview locally
Open `index.html` in a browser. For best results, use a small local web server or the VS Code Live Server extension.

## Personalize before publishing
1. Replace `ASWIN` and the introductory text in `index.html`.
2. Replace `your-email@example.com` with your real email address (search in `index.html`).
3. Replace the sample Unsplash image URLs in `style.css` with your own project images. Upload images to the repository (for example, an `images` folder) and use paths such as `url("images/exterior-01.jpg")`.
4. Update the project category names and descriptions.
5. Update the copyright year if needed.

## Free hosting with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a new public repository, for example `aswin-portfolio`.
3. Upload `index.html`, `style.css`, `script.js` and your `images` folder to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish. Your address will look like `https://YOUR-USERNAME.github.io/aswin-portfolio/`.

No build tools or paid services are required. Google Fonts and the sample Unsplash images use internet access; replace them with local images if you want the site assets fully self-contained.
